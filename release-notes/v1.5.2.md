这一版是健壮性审查的结果：修掉三处会让人踩空的地方，并给写配置加了写后校验。

## 改了什么

- **快照现在自带 `patches/`。** 以前只存 4 个配置文件，而 `pnpm-workspace.yaml` 里的 `patchedDependencies` 指向 `patches/*.patch`。恢复到新目录（或补丁目录丢了）时，pnpm 会报 `ERR_PNPM_PATCH_NOT_FOUND`，而报错完全不提"快照少收了东西"。
- **`restore` 先预检补丁。** 引用补丁但 `.patch` 不在，直接在动作前说清楚，不再等 pnpm 抛冷僻错误码。
- **写配置后有回读校验。** `minimal` / `restore` 写出的 `package.json` 会立刻解析一遍；不合法就停在那里，而不是让宿主在下次启动时才炸。
- **冻结安装失败会回退重试一次。** 快照里的 lockfile 与 package.json 对不上时，不再一次失败就结束。
- **`restore 名字` 支持位置写法**，不用每次都敲 `-Snapshot`。
- **`snapshots` 显示"为什么拍的"**：`before-minimal` / `before-restore` / `manual` / `guide`，选还原点时不用靠时间猜。

## 仍然没解决（如实写）

- 快照体积：每份含 17MB 补丁，保留 12 份约 200MB。
- 乙类故障的机理仍是推断，没读到宿主源码那一行。
- 只在 Windows + PowerShell 7 上验证过。
