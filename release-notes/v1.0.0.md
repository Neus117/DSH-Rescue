首版。

DSH 桌面端起不来时用它：先判故障类型，再走对应的一条路。只动配置层，不碰会话、附件、记忆、锚点、凭据。

## 你会得到什么

- **带路的向导。** 不带参数运行，它看现状 → 判类型 → 说清"打算做什么 / 为什么 / 做完看什么" → 问过你才动手。应用还在跑、而这一步必须关掉应用时，它不执行，只让你先退出。
- **五类故障，各走各的路。** 装载树没起来、依赖树被改坏、主进程握手失败、配置文件带 BOM、`.env` 写了越权的键——修法互斥，用错一条不但无效，还会把插件配置一起丢掉。
- **修完能核对。** `verify` 比对"最近一次启动"和"最近一次崩溃"，判定是真的好了还是又崩了。
- **每一步都能退。** 破坏性操作先存快照（含 `patches/`），保留 12 份；`rollback` 列出所有快照让你挑。
- **不要求你复述日志。** 认不出的错误会写一份报告（崩溃原文 + 配置 + 快照清单），不用你在终端里对着空气描述症状。

## 验证

- 用副本跑全链：`snapshot` → `minimal` → `restore` → `rollback`，退出码 0
- 快照自包含：从快照恢复到空目录，8 个依赖、113 个包装成
- `reset-cookies` 在假目录上验证：坏 Cookies 判坏并改名、健康的默认不误报
- 五类故障各对应一份真实崩溃日志，`diagnose` 均能判出

## 安装

```powershell
pwsh -NoProfile -File "$env:USERPROFILE\.dsh\rescue\dsh-rescue.ps1" install
```
