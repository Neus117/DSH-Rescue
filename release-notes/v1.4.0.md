现在不带参数运行就等于进入向导，不再需要你先判断该用哪条命令。

## 你会看到什么

- **`dsh-rescue` 直接带你把问题走完。** 三步：看现状 → 判类型 → 给出"打算做什么 / 为什么 / 做完看什么"，**问过你才动手**。你说 n，它只把该抄的命令打出来。
- **新增 `verify`：修完重启后核对。** 它比对"最近一次启动"和"最近一次崩溃"的时间，判定是真的好了还是又崩了——以前这一步只能靠你自己感觉。
- **向导不会硬来。** 应用还在运行、而这一步必须关掉应用时，它直接告诉你"先退出应用再重跑"，不执行。

## 一个真实用例

```
» 2/3 判断
  最新崩溃：11/11/2026 16:06:04
  错误行  ：DesktopHostFatalError: Unexpected token '﻿', "﻿{
  类型    ：丁 类

» 3/3 建议
  打算做：strip-bom
  为什么：配置文件开头有 UTF-8 BOM，宿主 JSON.parse 直接失败。只减 3 字节，不动内容。
  做完看：启动应用，能进主界面就回来跑 dsh-rescue verify
```

## 顺带

- 分型判定收敛成**一个函数**，`diagnose` 和向导共用，不会再出现"两处逻辑各说各话"。
- README 顶部改成这套三步，参考表格留在后面。

## 验证

只读命令 `status` / `verify` / `diagnose` 均正常；向导在"应用运行中"这一路正确拒绝执行并给出下一步；`verify` 判定"应用在运行且启动后无新崩溃"。

## 安装

```powershell
pwsh -NoProfile -File "$env:USERPROFILE\.dsh\rescue\dsh-rescue.ps1" install
```
